# 🚗 Camry iDrive Display & Console Controller Simulator

An interactive web-based OEM+ automotive infotainment display and physical console controller simulator designed for a **2012 Toyota Camry**. Combines a responsive 1280x800 center screen interface with an interactive 3D **BMW iDrive rotary controller** featuring mechanical audio-tactile click feedback.

---

## ⚡ Highlights

- **🖥️ 1280x800 Automotive Center Display**:
  - Replicates a luxury OEM+ head unit interface with cool blue Toyota Optitron illumination accents.
  - Live glanceable performance monitoring page: RPM, vehicle speed, engine coolant temperature, and fuel economy.
  - Multi-theme display engine with smooth transition animations.
- **🕹️ Interactive 3D iDrive Controller Simulator**:
  - Full rotational rotary knob simulator (CW / CCW rotation, 8-way directional nudge, center push button).
  - Synthesized mechanical detent click sounds matching automotive tactile rotary controllers.
  - Direct keyboard and touch binding controls for testing console hardware interactions.

---

## 🚀 Quick Start

No build step or Node.js server required—runs completely on vanilla web technologies:

1. Clone the repository.
2. Open [`index.html`](index.html) in any modern desktop or tablet web browser.
3. Use your mouse or keyboard controls to rotate and toggle the iDrive controller and navigate the vehicle UI panels.
